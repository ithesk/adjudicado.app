# Soporte de pared TL-SG108

Soporte con peine de cables para el switch TP-Link TL-SG108 (158 × 101 × 25 mm).

| Archivo | Uso |
|---|---|
| `SoporteTLSG108.step` | Abrir directo en Fusion 360 (File → Open). |
| `SoporteTLSG108.py` + `.manifest` | Script de Fusion: Utilities → Add-Ins → Scripts → **+** → elegir esta carpeta → Run. Medidas editables al inicio del archivo. |
| `SoporteTLSG108.stl` | Para el slicer. |
| `vista-previa-3d.html` | Vista 3D conceptual (necesita internet para cargar three.js). |

Antes de imprimir: medir el switch y ajustar `PORT_FIRST_X`, `PORT_PITCH` y `POWER_X`.
Imprimir con la placa sobre la cama; los labios frontales y la franja inferior necesitan soportes.
